# 可视化详解的内容结构

使用 `assets/details-example.html` 中的类，不需重新造阅读视图。模型内容由本次证据填写。每个主要模块至少包含一幅真实操作流程，随后解释公式和状态。

## 信息编排

- 默认用 HTML 流程节点构建阅读视图：全宽输入 → 2–4列有标题的分支 → 明确汇合/输出。形状跟随操作；局部公式与简短说明放在所属分支卡内。用正文补充差异和边界，不在图后重复讲述整条链路。
- 海报和详解使用同一事实，但分别排版。不要把海报面板直接复制到全宽 `.card`；那会同时放大字体、空白和长连线，并让读者滚动多屏才能对照公式。复杂交叉依赖可以用 `.diagram` 局部 SVG 配合旁侧说明，或拆成保留接口的子图。
- 阅读图保留数据支路与算术汇合，HTML 的并列分支应明确标注输入来源、输出去向。不能因卡片排列方便而把 gate/共享专家画成串行流程。
- 长表只展示一次。主流程与逐层网格优先并列；详细40/80层来源表可放原生 `<details class="disclosure">` 中供展开、打印和无JS阅读，避免重复网格后再占据数屏。
- 章节使用有语义的短眉题，如 `SPARSE RETRIEVAL` / `RESIDUAL MIXING`，避免每节都写同一个 `ARCHITECTURE`。依据与精度边界紧邻其所解释的操作。

## 页面结构

- **概览**：meta.json提供模型摘要和4–6个指标。`overview` section左侧主数据流，右侧层调度。主干特殊注入只标在实际层。复杂混合模型用静态生成的layer-grid；全部按钮/层类型写入HTML，JS只做选中说明。
- **Decoder/残差**：用“输入残差 → 读取/混合 → 子层 → 写回”的结构显示边界，显式画出原始残差支路。最终mixer与norm以源码为准。
- **各Attention/记忆模块**：用grid3/grid4表示内容Q/K/V、衰减门、写入门、输出门等并行支路，再用单独的宽节点表示汇合运算。颜色跟随海报。全是纵向节点且省略并行gate/value不算完整。
- **MoE**：router/Top-K、路由专家、共享专家及共享gate（如有）分别展示，最终汇合。权重和选择bias的区别放公式块。
- **状态与公式**：两列布局，一列公式，一列缓存框；包含prefill/decode差别、精度、逻辑容量与分片口径。
- **可选模块**：视觉、MTP等按已公开程度绘制；未知内部只画可追溯边界，不猜细节。
- **来源**：每节简短固定revision链接，末节汇总事实/推导/部署策略/待确认及配置键、源码符号。长URL不能挤破页面。

## 组件用法

- `section > .section-head`：英文短眉题/编号 + h2 + sub。
- `.grid2/.grid3/.grid4`：2/3/4列，自适应窄屏。`.card`容纳一个分支；`.node.theme-recurrent`等是操作，`.arrow`是垂直依赖，`.shape`标形状。
- `.flow-row`：短串行流程的横向节点与右箭头；窄屏自动转为纵向下箭头。只用于确实串行的步骤。
- `.diagram`：局部SVG容器；`svg`内嵌样式并使用局部ID，避免与海报的text/marker样式相互污染。可通过 `--diagram-min-width` 指定窄屏下保持可读的最小宽度并允许容器内滚动；不依赖缩成不可辨认的字来适配手机。
- `.disclosure`：可展开的补充调度/参数表。核心运算与必要说明保留在展开区域外；构建器为打印添加自动展开行为。
- `.formula`：可复制的公式，短行优先；不要把整模块说明写进pre。
- `.cache`：历史状态而非当前激活；`.note`为口径说明，`.note.important`为影响理解的例外。
- `.legend > .theme-*`与`.tag.theme-*`：语义图例/类型。
- `.table-wrap > table`：参数/状态比较；避免“参数表就是架构”的退化。
- `.layer-grid[data-layer-grid][data-inspector="layer-inspector"]`内的button有`data-layer-info`；生成完整静态层信息并保留分组调度表。模板控制器只更新inspector，不计算模型事实。

少量单链操作可用HTML node/arrow表达；有交叉依赖、旁路或多路合流的模块应使用内联SVG或明确的并列分支 + 汇合节点。不要用一串文字箭头隐去拓扑。形状与缓存开关仅改变辅助标注，不可隐藏核心计算节点。
