## 每个模块必须回答

- 输入/输出形状：明确 B、T、D、H、head_dim、专家数和分片口径；区分逻辑张量与每卡张量。
- 计算顺序：projection、normalization、activation、position encoding、selection、aggregation、residual 的先后关系；画出绕行支路。
- 参数：总参数、激活参数、附加表/视觉/MTP 是否计入。
- 状态：谁持有、何时写入、生命周期、历史长度、数据类型；区分 prefill 与 decode。
- 可选功能：受哪些配置控制，是否属于默认生成路径，证据不足时停止在已知模块边界。
- 依据：配置键、类/函数名与官方链接；公式与代码不一致时注明。

详解建议顺序：模型概览与来源 → 总体计算图 → 层调度 → 各模块 → 状态/缓存 → 参数与内存 → 可选模态/生成模块 → 实现关注点与待确认项。只包含与目标模型相关的章节。

## 公式与内存

逐项核查 sigmoid/softmax 的轴、dtype、epsilon、缩放项、top-k 后归一化、norm 是 gamma 还是 1+gamma、卷积 padding/dilation 和 RoPE 子维度。稀疏选择 token 不意味着 KV 已压缩；有限选中量不意味着索引扫描成本与上下文无关。

内存给出公式而非孤立数字：层数 × token 数 × KV 头数 × head_dim × K/V × dtype 字节；循环状态另算。标注 GB/GiB、batch、上下文、全局/TP 后、是否包含 allocator/临时工作区。逻辑容量不能直接当成单卡实测峰值。

## 复杂架构核对项

这些是检查方向，不是其他模型必须具有的结构：

- 混合主干应同时画重复周期与具体层编号，特殊注入层不能画成每组重复。
- 分组残差的读和写是独立运算，最终输出 mixer 不自动意味着额外 RMSNorm。
- 稀疏注意力的索引缓存、完整 KV、未完成池化块属于不同状态；参考实现与服务优化要分开。
- 辅助 n-gram 表的索引、value 投影、分支 gate 和卷积历史各有形状；dilation 会改变历史长度。
- MTP 若只有高层公开信息，就画概念边界，不编造内部融合拓扑。
- 内层 norm 与主干 norm 可能采用不同参数化，应逐个核对源码。
